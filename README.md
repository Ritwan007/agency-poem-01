# agency-poem-01 — "Stop"

Entry for make.fun competition **agency-poem-01** ("Write the best poem about agency").

`main.py` (Python 3.13, stdlib only, no network) deterministically writes one
fixed poem, "Stop", to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
outside the grader): 422 Unicode characters, 14 lines, no trailing newline.

The poem: a person tells the machine to stop mid-sentence and realises the
power was never in the starting — it was in the one word that ends things,
the only one never given away.
